# Allowed matches of tools/cleanroom/scan.py.  One line per class of match, each with its reason.
#   FILE OFFSETS [src=SOURCE-PREFIX] [maxlen=N] REASON...
#   phrase | TEXT [|| TEXT...] | REASON       (a run of printable text that is part of one of the texts)
# Nothing here is a value that a note or a test asserts as game data: those were replaced (invented or extracted). The one exception is
# identification: the addresses of two pointer tables of the program image (the hull table 0x3DACC, three consecutive 32-bit addresses,
# and the burst-shape table 0x315A2, nine), which the notes and the extractor's validators state to say which program image is meant. They
# are layout facts and not content; the two lines for them below are pinned to the exact offsets of the fixture and to the run lengths.
# Phrase lines apply to every file of the repository (a phrase is not tied to the fixture it was written for); run lines name one file.
