# sky-ground: rig, models and checks for note 04

Models (`gmodel.py` ground polygon, `fmodel.py` fill, `zones.py` sea-zone flags, `meshmodel.py` sea mesh pass) and their checks against the original code run in the Musashi rig
(`rigw.py`, `meshrig.py`, `rigblit.c`; build with `build.sh`) and against emulator frames (`check_frames.py`, `check_mesh.py`, `check_meshmodel.py`). All scripts need
`extracted/interceptor.bin` and `build/sky-ground/librigblit.so`; `check_rig.py` and the others exit with a message when either is missing.

Licence flag: `rigblit.c` ports vAmiga's blitter logic and so is GPL-3.0 (see its header). The repository licence is for the owner to decide; this directory must not be
relicensed until that is settled.

Memory: each `rigw.stage()` allocates a 16 MiB rig and `rig_init` frees the previous one (150 stages stay at about 28 MB); the scratch planes of a long loop are the only growth.

Staging and log checks: `check_stage.py SCRIPT LOG` verifies that the pokes of a staged capture script took (the last pokes before each `log` against the record and the state block, and the octant against the heading word the camera used); `check_zone_logs.py` compares the zone-flag model with the flags of every state block in the capture logs. The capture scripts are generated by `tools/vamiga-ref/scripts/gen-sky-ground.py` (the mesh retakes `sky-ground-mesh-r*.txt` and the stale-colour sampling scripts `sky-ground-stale-colour-*.txt` included, except the deck script, which is the same sampling on `cockpit-ground.vasnap`).
